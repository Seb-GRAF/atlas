## Design Context

### Users
This is a personal apartment-search dashboard for a French-speaking user in Switzerland. The main job is to scan listings, review the newest viable apartments quickly, and track follow-up status.

### Brand Personality
Utilitarian, calm, decisive. The interface should feel like a compact operations tool, not a marketing page or a multi-user product.

### Aesthetic Direction
Keep the existing dark dashboard direction, dense information layout, French UI labels, and low-friction controls. Prefer fewer choices and direct access to the newest listings.

### Design Principles
- Default to the user's single active profile.
- Prioritize newest listings over score/filter-heavy workflows.
- Show only information that helps decide whether to contact or follow up.
- Keep failures visible and debuggable instead of hiding degraded states.
