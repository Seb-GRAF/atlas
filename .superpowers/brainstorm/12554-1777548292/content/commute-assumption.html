How should commute time be calculated?

I found that the current code has pieces for geocoding, driving, transit, and route cache, but the scraper clears the commute fields instead of computing them. Before designing the fix, we should choose the commute baseline.

A

Arrive at work by 08:00

Best for apartment hunting. Stable comparison across listings, useful for public transport schedules.

B

Leave home at 07:30

Also realistic, but less directly tied to a work start time. Public transport results may vary more.

C

Configurable per profile

Add profile settings for arrival/departure time and day. More flexible, slightly larger implementation.
